🏗️ Arquitectura Técnica — Carga de Actividades
📌
Esta sección define cómo se cargan, validan y sincronizan las actividades del Mes SSTA desde el sistema de administración hacia los participantes.
🔄 Flujo de carga de actividades
1️⃣
Admin crea / activa actividad
Panel Admin → Actividades → Toggle ON/OFF · Se define XP, semana, tipo y condiciones de validación
2️⃣
Validación de parámetros
Sistema verifica: fechas activas, empresa destino, XP asignado, tipo de evidencia requerida (foto / texto / QR / automático)
3️⃣
Publicación a participantes
Actividad aparece en la pestaña correspondiente del participante filtrada por su empresa/centro/semana
4️⃣
Participante completa actividad
Envía evidencia → Sistema valida → Acredita XP automáticamente → Actualiza ranking e insignias
5️⃣
Reporte en tiempo real
Dashboard Admin actualiza contadores · Reportes disponibles para exportar a Excel / PDF / Power BI
